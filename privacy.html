요약: 환율 기록은 회원가입이 없고, 이용자의 개인정보를 수집·저장하거나 다른 곳에 제공하지 않습니다. 광고, 분석 도구, 위치 정보도 사용하지 않습니다.

오상플레이(이하 "운영자")는 「개인정보 보호법」 등 관련 법령을 지키며, 환율 기록 앱과 웹페이지(이하 "서비스")를 이용하는 분의 개인정보를 다음과 같이 다룹니다.

1. 수집하는 개인정보

서비스는 이름, 연락처, 이메일, 위치, 기기 식별자(광고 ID 포함) 등 어떠한 개인정보도 수집하지 않습니다. 회원가입이나 로그인 기능이 없고, 이용자가 입력하는 정보도 없습니다.

2. 서비스 이용 중 발생하는 통신

서비스는 환율 정보를 보여주기 위해 GitHub, Inc.가 운영하는 GitHub Pages(ex-rate-osw.github.io)에서 공개 환율 데이터 파일을 내려받습니다. 이 과정에서 일반적인 웹 접속과 마찬가지로 접속 IP 주소, 접속 시각, 기기·브라우저 정보 등이 GitHub의 서버 기록에 남을 수 있습니다.

  • 이 기록은 GitHub가 자체 정책에 따라 처리하며, 운영자는 이 기록을 받아보거나 이용하지 않습니다.
  • GitHub의 개인정보 처리에 관한 내용은 GitHub 개인정보 처리방침에서 확인할 수 있습니다.

3. 기기에 저장하는 정보

앱은 화면에 표시하기 위해 내려받은 환율 데이터를 앱이 실행되는 동안에만 메모리에 보관하며, 이용자를 식별할 수 있는 정보는 기기에 저장하지 않습니다. 웹페이지는 쿠키를 사용하지 않습니다.

4. 개인정보의 제3자 제공 및 처리 위탁

운영자는 수집하는 개인정보가 없으므로 제3자에게 개인정보를 제공하거나 처리를 위탁하지 않습니다.

5. 개인정보의 보유 기간 및 파기
