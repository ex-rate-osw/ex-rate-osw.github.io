## 1. 업로드 키 만들기 (PC에서 한 번만)

Play는 **업로드 키**로 서명한 파일만 받아요. 실제 배포 서명은 Google이 관리(Play 앱 서명)하고, 업로드 키는 잃어버려도 Play Console에서 재설정 요청이 가능해요.

PowerShell:

```powershell
# Android Studio에 들어있는 keytool 사용 (경로가 다르면 맞게 바꿔 주세요)
$kt = "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe"
& $kt -genkeypair -v -keystore "$HOME\Documents\ex-rate-upload.jks" `
  -alias upload -keyalg RSA -keysize 2048 -validity 10000 `
  -dname "CN=Ohsang Play, C=KR"
# 비밀번호를 두 번 묻습니다. 키 비밀번호도 같은 값으로 하면 편해요.

# GitHub Secret에 넣을 base64 (클립보드로 복사)
[Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\Documents\ex-rate-upload.jks")) | Set-Clipboard
```

- `ex-rate-upload.jks` 파일과 비밀번호는 **따로 백업**해 두고, 저장소에는 절대 올리지 마세요.

**저장소 Secrets** (Settings → Secrets and variables → Actions → New repository secret)

| Name | 값 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | 위에서 복사한 base64 |
| `ANDROID_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `ANDROID_KEY_ALIAS` | `upload` |
| `ANDROID_KEY_PASSWORD` | 키 비밀번호 (같게 했으면 같은 값) |

**빌드**: Actions → **Android 빌드 (Play 스토어용 AAB)** → Run workflow
- 5~10분 뒤 실행 화면 아래 **Artifacts → android-aab**를 내려받아 압축을 풀면 `app-release.aab`가 있어요.
- 실행 요약에 "업로드 키로 서명해요"가 떠야 해요. "업로드 키 없음" 경고가 뜨면 Secrets를 다시 확인해 주세요.

- **개인정보처리방침의 개발자명**: 스토어에 표시되는 개발자명("오상")과 방침의 운영자가 같아야 해요. 방침의 운영자 칸에 `오상플레이 (Google Play 개발자명 "오상")`로 적어 뒀어요.

- **버전 코드**: 같은 번호는 다시 못 올려요. 워크플로를 다시 실행하면 자동으로 1씩 올라가요.
